## 📌 Phase 1: Computer Networking & Linux Fundamentals
- **Networking Core:** OSI 7-Layer Model, TCP/IP Suite, DNS, DHCP, Subnetting, CIDR, ARP, Routing, NAT, Firewalls, VPNs.
- **Protocols & Analysis:** HTTP/HTTPS, SSH, FTP, SMB, SMTP, TLS/SSL handshake analysis via **Wireshark**.
- **Linux Command Line Mastery:** File system hierarchy, permissions (chmod/chown), process management, bash scripting, cron jobs, network configuration.
- **Essential Distros:** Kali Linux, Parrot Security OS, Ubuntu Server.

---

## 📌 Phase 2: Programming & Scripting for Hackers
- **Python for Security:** Socket programming, requests library, building custom scrapers, port scanners, and brute-forcers.
- **Bash Scripting:** Automating recon workflows, piping tools (subfinder, httpx, nuclei).
- **JavaScript & Web Technologies:** DOM architecture, browser security models, SOP (Same-Origin Policy), CORS, WebSockets.
- **C/C++ Basics:** Memory allocation, pointers, buffer overflows, understanding binary execution.

---

## 📌 Phase 3: Web Application Security & OWASP Top 10
- **OWASP Top 10 Vulnerabilities:**
  - SQL Injection (Error-based, Blind, Time-based)
  - Cross-Site Scripting (Reflected, Stored, DOM-based XSS)
  - Broken Access Control & IDOR (Insecure Direct Object Reference)
  - Server-Side Request Forgery (SSRF)
  - Security Misconfigurations & XML External Entity (XXE)
  - Authentication & Session Hijacking
- **Tooling:** Burp Suite Professional, OWASP ZAP, Postman, ffuf, dirsearch, sqlmap.

---

## 📌 Phase 4: Network Penetration Testing & Active Directory
- **Reconnaissance & Scanning:** Nmap advanced timing and NSE scripting, Masscan, Netdiscover.
- **Vulnerability Assessment:** Nessus, OpenVAS.
- **Exploitation Frameworks:** Metasploit Framework, Searchsploit.
- **Active Directory Exploitation:**
  - LLMNR/NBT-NS Poisoning (Responder)
  - Kerberoasting & AS-REP Roasting
  - Pass-the-Hash / Pass-the-Ticket
  - BloodHound graph analysis & Domain Privilege Escalation.

---

## 📌 Phase 5: Bug Bounty Hunting & Vulnerability Disclosure
- **Reconnaissance at Scale:** Subdomain enumeration, ASN discovery, port scanning, URL crawling.
- **Methodology:** Target scoping, recon data organization, manual flaw identification over automated scanning.
- **Reporting:** Writing professional, reproducible PoCs on platforms like HackerOne, Bugcrowd, and Intigriti.

---

## 📌 Phase 6: Reverse Engineering & Exploit Development
- **Disassemblers & Debuggers:** Ghidra, x64dbg, IDA Free, GDB with PEDA/GEF.
- **Fundamentals:** Stack frames, registers, assembly instructions (x86/x64).
- **Binary Exploitation:** Buffer overflows, Return-Oriented Programming (ROP), shellcoding.
